# roadmap-sh-django

Django + Django Ninja の学習リポジトリ。REST API で作る（SSR はやらない）。

## 進め方

```
docs/_prompt.md を読んで、M0 を実行して
```

以降は `M1: 第1部 ステップ1` から順に。
分からない言葉が出たら **`?: <言葉>`** と送れば、そこだけ解説が返る。

| モード | 呼び方 |
|---|---|
| ステップ生成 | `M1: 第1部 ステップ3` |
| 部末パック | `M2: 第1部` |
| プロジェクト | `MP: url-shortening-service` |
| 拡張モジュール | `MX: celery` |
| 用語質問 | `?: マイグレーション` |

## 決めたこと

- カスタムユーザーモデルは第1部の最初に入れる（あとから変更できないため）
- 認証は JWT。第1部では入れない
- 管理画面は「データを見る窓」としてだけ使う。カスタマイズは学ばない
- 画像は Pillow + ローカル保存。S3 は後回し
- pre-commit は第2部から
